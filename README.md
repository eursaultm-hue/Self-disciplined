# Personal Learning OS — V0.2

一个以 **AI 学习管家** 为核心的个人学习操作系统。

## 产品原则

> **用户输入越少，AI 完成的管理越多。**

这不是普通 Todo App。用户不需要每天维护完整任务表，而是通过自然语言告诉管家“今天发生了什么”，系统负责把现实信息转换成任务状态、计划调整和长期记忆。

## 核心循环

`现实信息 → AI 理解 → 计划 → 主动提醒 → 执行 → 记录 → 复盘 → 自适应调整`

## V0.2 已实现

- AI 管家首页，而不是传统任务列表首页
- 自然语言反馈入口
- 本地 Steward Decision Layer：先用确定性规则处理常见反馈
- 长期记忆摘要
- 今日计划与 Must / Should / Could
- 任务完成、未完成、理解困难等反馈自动关联
- 通知权限入口
- V0.1 数据兼容迁移
- 移动端优先界面

## 下一步

1. 接入真正的 LLM Agent，而不是只使用本地规则。
2. 增加主动通知调度器。
3. 增加日历/课表/文件权限与自动读取。
4. 增加学习行为模型和动态计划。
5. 建立安全的后端 AI Gateway，避免把模型 API Key 放进 APK。
6. 最终形成真正的 Personal Learning OS。

## 运行

```bash
npm install
npm run dev
```

数据默认保存在设备本地。后续版本会增加 schema migration，保证 APK 更新不会破坏学习数据。
