# V0.7 法语学习引擎

## 目标
把 V0.6 的「PDF → 课程结构」升级成真正服务于数学分析、线性代数、电子学法语授课的学习系统。

核心链路：
PDF → Chapitre/Section → Définition/Théorème/Propriété/Formule → 知识点 → 法语术语 → 理解状态 → 学习任务 → 复习 → AI 管家监督

## V0.7 功能

### 1. 专业法语词汇
数学：dérivée, continuité, limite, convergence, fonction, ensemble, application, matrice, déterminant
电子学：courant, tension, résistance, condensateur, circuit, fréquence, puissance, signal
每个词保存：法语、中文、课程、上下文、符号/单位、掌握状态。
掌握状态：陌生 → 见过 → 能认 → 能理解 → 能应用

### 2. PDF 知识点增强
在 V0.6 基础上增加 Chapitre / Section 层级、Définition / Théorème / Propriété / Formule 分类、中文解释、法语原文、专业词汇关联、符号/单位、前置知识、掌握度、关联学习任务。

### 3. 学习障碍记录
把自然语言输入转成结构化障碍：language、concept、prerequisite、pace、fatigue、time。
例如用户说「今天电子学完全没听懂」，系统先形成候选原因，不武断判断，再生成低成本确认和对应补救任务。

### 4. SRS 复习
先做轻量版本：reviewDueAt、interval、ease、reviewCount、lastReviewedAt。
复习对象包括法语专业词和知识点，不做复杂算法，先让真实学习数据跑起来。

### 5. AI 管家联动
新增 Action：CREATE_REVIEW_TASK、UPDATE_KNOWLEDGE_STATUS、UPDATE_TERM_STATUS、RECORD_LEARNING_BLOCKER。
管家根据最近听不懂的知识点、掌握度、到期复习项、考试/任务压力生成下一步任务。

## 数据原则
课程知识库、学习任务、学习记录使用稳定 ID 关联。
V0.7 升级不得清空已有数据。
所有 V0.7 数据进入 JSON 备份/恢复。
本地优先，PDF 默认不上传。
Gateway 可选，没有 Gateway 时保持离线可用。
API Key 不进入 APK。

## 开发顺序
1. 数据模型与迁移
2. 专业法语词汇库
3. 知识点详情页
4. SRS
5. 学习障碍记录
6. Steward/Action 联动
7. Supervisor 联动
8. 备份/恢复兼容
9. Android 构建与实际测试

## 暂不做
IELTS 引擎、多 Agent、复杂 RAG、桌宠、自动 OCR、自动判断用户是否真的学习、一键静默 APK 更新。

## 验收标准
导入数学分析 PDF → 看到章节/知识点 → 看到法语术语 → 标记掌握状态 → 系统安排复习 → 复习结果进入学习记录 → 管家知道下一步该做什么。
用户说「电子学听不懂」 → 系统记录障碍 → 生成对应补救任务 → 完成后更新知识点状态。
