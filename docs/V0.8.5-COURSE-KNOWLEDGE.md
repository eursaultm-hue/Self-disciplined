# V0.8.5 课程知识系统设计

## 目标
把当前“PDF 导入 + 简单候选知识点 + SRS”升级成真正可长期使用的课程知识库，同时保持 V0.8.1 的数据兼容，不引入云端存储。

## 核心闭环
PDF → 文档 → Chapitre/Section → 知识点 → 学习/复习 → 掌握状态 → 任务 → 今日计划 → 学习记录 → 复盘。

## 本阶段范围

### 1. 课程层
- 课程独立管理：数学分析、线性代数、电子学等。
- 文档属于课程，避免多个 PDF 混成一锅。
- 文档显示导入时间、页数、知识点数量。

### 2. 文档结构层
- 保留原始顺序。
- 识别 Chapitre / Section / Définition / Théorème / Propriété / Proposition / Formule / Exemple。
- 每个结构节点保存来源页码和原文。
- 支持展开/折叠浏览。

### 3. 知识点层
- 知识点类型、重要度、来源结构、原文。
- 增加“掌握状态”与最后学习时间。
- 支持手动编辑标题和类型，避免解析器把人类课程材料搞成垃圾分类学。

### 4. 学习层
- “开始学习”进入知识点学习会话。
- 会话结束记录实际时间、状态和备注。
- “我会了 / 还不会”继续驱动 SRS。
- 到期复习自动进入任务池，避免知识库成为电子墓地。

### 5. 任务与计划
- 知识点任务必须带 knowledgePointId。
- 同一知识点避免重复活动任务。
- SRS 到期复习进入今日计划。
- 从知识点页面创建任务后，返回今日计划立即可见。

### 6. 数据兼容
- 继续使用 personal-learning-os-knowledge。
- 保留 V0.6/V0.7 数据迁移。
- 不删除旧字段。
- 备份/恢复继续覆盖课程知识库。

## 暂不做
- OCR
- 云端 RAG
- 自动 AI 总结
- 多 Agent
- 在线 PDF 同步
- IELTS 知识库
- 桌宠

这些东西现在都很诱人，但核心闭环还没稳定时，继续加功能只是在给混乱装更漂亮的门。

## 验收标准
1. Android 中能稳定进入课程知识库。
2. 能选择 PDF 并导入。
3. 导入后课程、文档、章节、知识点关系清晰。
4. 知识点可进入学习/复习。
5. 复习状态能进入任务和今日计划。
6. 重启/更新 APK 后数据不丢。
7. npm test、Next build、Android APK 全部通过。
